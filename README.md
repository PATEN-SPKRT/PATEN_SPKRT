
PATEN-SPKRT 
adalah sistem informasi terintegrasi yang dirancang khusus untuk mendukung alur kerja pengumpulan data SPKRT. Aplikasi ini berfungsi sebagai alat kontrol, manajemen lapangan, hingga monitoring progres secara real-time bagi berbagai tingkatan pengguna, mulai dari petugas lapangan hingga level pengambil kebijakan di tingkat provinsi.
Pengguna: 
Super Admin
     - Mengelola hak akses dan manajemen pengguna untuk seluruh tingkatan akun (Admin Provinsi, Admin Kab/Kota, PPL, PML, dan Validator).

Admin Provinsi, Kab/Kota
      - Melakukan alokasi NKS (Nomor Klaster Sampel) dan alokasi DSRT (Daftar Sampel Rumah Tangga) kepada masing-masing petugas pengumpulan data.
      - Mengelola akun pengguna di wilayah kerjanya.

PPL (Petugas Pendataan Lapangan)
     - Melihat alokasi DSRT sesuai.
     - Melakukan upload dokumen/kuesioner hasil pendataan lapangan ke dalam sistem.

PML (Petugas Pemeriksa Lapangan)
    - Memeriksa hasil upload kuesioner dari PPL.
    - Melakukan entry data ke dalam sistem berdasarkan kuesioner fisik/digital yang telah di-upload.
    - Melakukan validasi entrian untuk memeriksa akurasi, kelengkapan, dan konsistensi dari isian data yang telah di-entry oleh PML.

✨ Fitur Utama
- Manajemen Pengguna (User Management): Pengelolaan akun, hak akses (role), dan pemetaan wilayah kerja untuk Admin dan Petugas oleh Admin berwenang.
- Manajemen Alokasi NKS & DSRT: Pengaturan, distribusi, dan pengelolaan Nomor Klaster Sampel beserta Daftar Sampel Rumah Tangga oleh Admin Kab/Kota kepada petugas.
- Upload Kuesioner Lapangan: Fasilitas bagi PPL untuk mengunggah dokumen hasil pendataan berdasarkan DSRT yang ditugaskan.
- Modul Entry Data (PML) SPKRT.BL, SPKRT.LK, SPKRT.S: Antarmuka input data yang terstruktur merujuk pada sampel rumah tangga di lapangan.
- Sistem Validasi & Kontrol Kualitas: Pengecekan otomatis dan manual terhadap akurasi serta konsistensi isian data untuk menghindari missing value atau inkonsistensi.
- Dashboard Monitoring & Pelaporan:
      -> Pemantauan progres lapangan (progress tracking) secara real-time.
      -> Laporan rekapitulasi setelah seluruh data selesai di-entry dan divalidasi.

       ▼

       │
       ▼

       │
       ▼

       ▼
